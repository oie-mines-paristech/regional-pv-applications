# regional-pv-applications

Applications using the [regional-pv](https://github.com/ramaroesilva/regional-pv/) library.

## Background

The `regional-pv` library has been applied in several European research initiatives, including the
[European Climate Energy Mixes (ECEM)](https://climate.copernicus.eu/european-climate-energy-mixes) in 2018
and [Clim2Power](https://jpi-climate.eu/project/clim2power/) in 2020.

Between 2022-2025, Yves-Marie Saint-Drenan and Rodrigo Amaro e Silva (Mines Paris – PSL & ULisbon)
integrated `regional-pv` in the [Pan-European Climate Database (PECD)](https://climate.copernicus.eu/powering-europe-through-climate-uncertainty)
model chain, funded by Copernicus Climate Change Services (C3S).

## Instructions

Each application is maintained in its own dedicated branch. To explore the available applications, check the list of branches in the repository.
